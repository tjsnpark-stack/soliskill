## 1. 전날 (D-1)

- [ ] `npm install` → `npm run dev -- --host` 로 실행 확인
  - 이 PC: **http://localhost:5173** · 같은 사내망 다른 PC: **http://(이 PC의 IP):5173** (실행 시 터미널 `Network:` 줄에 표시)
- [ ] **반드시 dev 서버로 시연** — `npm run build`/`preview`/`dist`로 열면 AI 프록시(`/api/messages`)가 없어 항상 규칙 기반으로만 동작
- [ ] (선택) `.env`에 `ANTHROPIC_API_KEY` 입력 → dev 서버 재시작 → 매칭 1회 실행해 **"🤖 AI 분석"** 배지 확인
  - 키가 없거나 실패하면 자동으로 "📐 규칙 기반"으로 전환 → 시연이 멈추지는 않음
- [ ] 시연 PC 브라우저: 크롬 최신, 화면 배율 100%, 창 최대화 (1280×720 이상에서 화면 깨짐 없음 확인됨)
- [ ] PPT 최종본 내려받기(.pptx 또는 PDF) — 발표 PC에 **Noto Sans KR** 글꼴이 없으면 PDF로 발표하는 게 안전
- [ ] 대본·PPT의 빈칸 확인: `[팀명]` `[발표자 이름]` `[연락처]`, 대본 Q18(개발 기간·역할)·Q19(어려웠던 점)

## 2. 시연 30분 전

- [ ] dev 서버 실행 중인지 확인 (터미널 창 닫지 않기)
- [ ] 로그인 화면 **🔄 데모 데이터 초기화** 클릭 → 초기 시연 상태로 복구
  - 프로젝트·성장 기록·**적합도 기준(60·8·100)**까지 초기값으로 돌아감
  - ⚠ 테마·저장된 아이디도 함께 지워짐 (라이트 테마로 돌아감)
- [ ] 브라우저 알림·메신저·자동 업데이트 끄기, 북마크바 숨기기
- [ ] 리허설 1회 전체 실행 → 끝나면 **다시 데모 데이터 초기화** (리허설 흔적 제거)

## 3. 시연 직전 (1분 전)

- [ ] 로그인 화면에서 대기 (아이디·비밀번호 비워두기 — 입력하는 모습도 보여주기)

## 4. 시연 동선 & 멘트

**계정** — 관리자·PM `admin` / `admin1234` · 직원 `r175`(윤승미) 또는 `r177`(박선우) / `1234`

**구성** — ① 메인 스토리 "연계 작업 할 사람을 찾아라"(3분 30초) → ② 빠른 기능 투어(1분 30초). 순서·멘트 전체는 대본 PDF의 "라이브 시연" 표를 그대로 따른다.

| 구간 | 핵심 장면 | 꼭 짚을 숫자 |
|---|---|---|
| ① 찾기 | 문장으로 "연계 작업…" 검색 → 추천 이유·가용 | 조성기 시스템 연계 **Lv.5**, 적합도 **92** |
| ① 기준 | 기준 펼치기 → 40·12 → **초기값으로** | 92 → 88 → 92 |
| ① 근거·현황 | 조성기 역량 상세 → 조직도에서 남윤우 | 남윤우 **Lv.4 · 가용** |
| ① 배치 | 원클릭 프로젝트 + Java 추가 → 조합 평가 | 커버리지 100%, **Java 박자영 1명** 경고 |
| ① 갱신 | 칸반 완료 → 매칭 결과 다시 보기 | 남윤우 **Lv.4 → 5**, 적합도 **88 → 96** |
| ② 투어 | 지사 보드·프로젝트 상세 → 마이페이지(공개 스위치·교육 기록) → 조직 역량(부서 필터) → 직원 추가(이력서) → 직원 `r175` 화면 → 다크 모드 | 제안서작성 **Lv.4 → 5** · 공개 스위치는 다시 켜 두기 |

### 동선 주의
- **기준을 바꿨다면 반드시 "초기값으로"** — 그대로 두면 이후 점수가 PPT·대본과 달라짐
- 갱신 숫자(88 → 96)는 **데모 데이터 초기화 직후** 기준 — 리허설 후 반드시 초기화
- 조직 역량으로 갈 때 **검색창 비우기** — 이전 검색어가 남아 있으면 "직원 0명"으로 보임
- 칸반 단계는 카드의 드롭다운으로 변경 (드래그 아님) · 완료 토스트는 약 4초 후 사라짐
- 직원 추가는 저장하지 말고 **취소** (저장하면 조직도·분포 숫자가 바뀜)
- 시간이 부족하면 ②를 통째로 생략

## 5. 돌발 상황 대응

| 상황 | 대응 |
|---|---|
| 매칭 결과가 "📐 규칙 기반"으로 나옴 | 정상 동작. "AI가 없어도 배치 업무가 멈추지 않도록 설계했습니다"로 연결 |
| AI 매칭이 오래 걸림(10~20초) | 버튼 문구가 "252명 역량 데이터 정리 중…" 등으로 바뀜 — "이름 대신 일회용 익명 ID와 역량만 보내 외부에서는 누군지 알 수 없습니다(🔒 안내)" 멘트로 시간 채우기 |
| 점수가 PPT(92점)와 다름 | 적합도 기준이 조정된 상태 → 기준 펼치기 → **초기값으로** |
| 화면이 이상하게 꼬임 | 새로고침(F5) → 다시 로그인 (데이터는 유지됨). 그래도 이상하면 로그아웃 → **데모 데이터 초기화** |
| 이미 완료된 프로젝트를 다시 완료로 | 성장은 1회만 반영됨(중복 없음) — 걱정 X |
| 페이지가 안 열림 | 터미널에서 `npm run dev -- --host` 재실행 → `localhost:5173`이 안 되면 `127.0.0.1:5173` |
| 시연 자체가 불가 | 백업: `docs/demo/soliskill-demo.webm` 영상 재생 (크롬에 끌어다 놓기) |

## 6. 예상 질문 (요약 — 전체는 대본 PDF 뒷부분)

- **"PM에게 묻는 것과 뭐가 다른가요?"** → PM은 자기 프로젝트 사람만 앎. 모든 PM이 아는 정보를 한곳에 모아 검색 한 번으로 전사에서 찾고 투입 가능 여부까지 확인
- **"적합도 기준은 어떻게 정했나요?"** → 팀이 정한 초기값(보유 여부를 숙련도 차이보다 크게). 정답이 없는 숫자라 관리자가 조정 가능, 기준은 화면에 공개
- **"AI 없이도 되나요?"** → 규칙 기반으로 자동 전환, 결과에 배지로 구분. 점수는 AI 모드에서도 같은 공식
- **"개인정보는?"** → AI에는 요청마다 새로 만든 일회용 익명 ID와 역량만 전송, 이름·연락처는 전송하지 않음
- **"인건비·원가도 되나요?"** → 현재는 직급·역량·투입 현황까지. 인건비·투입 계획·원가 계산은 다음 단계
- **"실데이터인가요?"** → 조직 구조·명단은 실제 기반, 스킬은 추정 생성 데이터. DB 없이 브라우저에서 동작하는 시연 버전
